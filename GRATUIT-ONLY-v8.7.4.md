# Aven v8.7.4 — mode strictement gratuit

Aven n’attribue plus de modèle payant. La table de priorités livrée ne contient que des modèles explicitement gratuits. Le chargeur filtre également les entrées payantes présentes dans un fichier d’espace de travail personnalisé, afin qu’elles ne puissent pas être utilisées par le routeur.

Le vocal est limité à Gemini Live via Google AI Studio ; le fallback OpenAI Realtime payant a été retiré.

OpenRouter reste optionnel et limité aux variantes gratuites. Les modèles OpenCode/Zen explicitement gratuits restent utilisables sans clé.
