# UI sources

Les contrôles de fenêtre utilisent des SVG locaux dessinés dans le style des contrôles Windows 11 / Fluent UI.
Référence d’icônes Microsoft : https://github.com/microsoft/fluentui-system-icons

La bibliothèque Fluent UI System Icons fournit des SVG monochromes qui héritent de `currentColor`, ce qui correspond au principe utilisé ici pour les trois contrôles de fenêtre.
